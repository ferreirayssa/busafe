Sobre o Projeto

O BuSafe nasceu para integrar tecnologia e segurança pública no transporte coletivo da Grande Vitória. Nosso objetivo é fornecer dados precisos para que cada cidadão capixaba possa planejar sua viagem com base na segurança das rotas.
